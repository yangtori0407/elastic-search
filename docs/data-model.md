## V1-T09-P · 문서 단위

* 개인 index 이름: `manga-books`
* 검색 결과 한 줄 / 문서 한 건의 의미: 만화 작품 1개
* 업무 ID field / 예시 값: `manga_id` / `MANGA-00001`
* ES `_id`와 업무 ID 관계: ES `_id`에 `manga_id` 값을 동일하게 사용한다.
* 문서 한 건이 사용자에게 보여 주는 정보: 제목, 줄거리, 장르, 연재 상태, 연재 시작 연도, 권 수, 종이책 1권 정가

## V1-T11-P · field 계약

| field          | 예시 값                           | 검색/필터/정렬/표시/집계 | type      | 질문 번호      | 선택 이유                                              |
| -------------- | ------------------------------ | -------------- | --------- | ---------- | -------------------------------------------------- |
| `manga_id`     | `MANGA-00001`                  | 필터·표시          | `keyword` | -          | 작품마다 고유한 ID이므로 값을 나누지 않고 정확하게 식별하기 위해 사용한다.        |
| `title`        | 장송의 프리렌                        | 검색·표시          | `text`    | Q1, Q2     | 작품 제목 전체 또는 제목에 포함된 단어를 이용해 검색할 수 있도록 사용한다.        |
| `description`  | 엘프 마법사 프리렌이 다시 여행을 떠나는 판타지 이야기 | 검색·표시          | `text`    | Q1         | 줄거리의 단어를 분석하여 `마법`과 같은 검색어로 작품을 찾기 위해 사용한다.        |
| `genre`        | 판타지                            | 필터·표시·집계       | `keyword` | Q1, Q2, Q3 | 판타지, 스포츠 등의 장르를 정확하게 필터링하고 장르별 작품 수를 집계하기 위해 사용한다. |
| `status`       | 연재중                            | 필터·표시          | `keyword` | Q1, Q2     | 연재중과 완결처럼 정해진 값을 정확하게 구분하기 위해 사용한다.                |
| `start_year`   | 2020                           | 필터·정렬·표시       | `integer` | Q2         | 특정 연도 이상인 작품을 범위 검색하고 연재 시작 연도를 기준으로 정렬하기 위해 사용한다. |
| `volume_count` | 15                             | 필터·정렬·표시       | `integer` | Q2         | 20권 이하와 같은 범위 조건을 적용하고 권 수를 기준으로 정렬하기 위해 사용한다.     |
| `paper_price`  | 7000                           | 필터·정렬·표시       | `integer` | -          | 특정 가격 이하·이상의 작품을 찾거나 가격순으로 정렬할 수 있도록 숫자형으로 저장한다.   |

* 배열/객체 여부와 제공 생성기 지원 범위: 현재 데이터 모델의 모든 field는 하나의 값을 저장하며 배열이나 객체 field는 사용하지 않는다. 제공 생성기의 지원 범위는 개인 데이터 생성 단계에서 확인한다.
* 제외한 개인정보/불필요한 field와 이유: 이용자 이름, 연락처, 검색 기록 등 개인정보는 저장하지 않는다. 이 PBL은 만화 작품 자체를 검색하고 분석하는 것이 목적이므로 이용자 개인정보가 필요하지 않다.
* 자가 점검으로 수정한 내용:

  * 개인 index 이름을 `manga`로 정의했다.
  * 업무 ID를 `manga_id`로 정의하고 ES `_id`와 동일한 값을 사용하도록 했다.
  * 범위 조건 `start_year >= 2018`과 의미가 일치하도록 검색 질문을 `2018년부터 연재를 시작한`으로 작성했다.
  * 질문별 검색어, 조건, 정렬 기준, 표시 field를 구분했다.
  * 대표 문서를 포함·제외·경계 역할로 구분하고 각 질문과 연결했다.
* 완전한 mapping: `../elasticsearch/index-create.json`
