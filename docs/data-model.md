# 데이터 모델 초안

## 1. 문서 단위

- 검색 결과 한 건은 무엇인가: 만화 작품 1개
- 이 문서 한 건이 사용자에게 보여 주는 정보:
  제목, 줄거리, 장르, 연재 상태, 연재 시작 연도, 권 수, 종이책 1권 정가

## 2. 대표 문서 예시

```json
{
  "manga_id": "MANGA-00001",
  "title": "장송의 프리렌",
  "description": "마왕을 쓰러뜨린 용사 일행의 모험 이후, 엘프 마법사 프리렌이 다시 여행을 떠나는 판타지 이야기",
  "genre": "판타지",
  "status": "연재중",
  "start_year": 2020,
  "volume_count": 15,
  "paper_price": 7000
}
```

> `paper_price`는 한국어판 최신 일반판 1권의 종이책 정가를 기준으로 한다.

## 3. 핵심 field와 역할

| field | 예시 값 | 검색에서 맡는 역할 | ES type 후보 | 선택 이유 |
|---|---|---|---|---|
| `title` | 장송의 프리렌 | 전문 검색·표시 | `text` | 사용자가 작품 제목이나 제목의 일부를 검색할 수 있다. |
| `description` | 엘프 마법사 프리렌이 다시 여행을 떠나는 판타지 이야기 | 전문 검색 | `text` | 사용자가 줄거리의 단어를 이용해 작품을 찾을 수 있다. |
| `genre` | 판타지 | 정확 조건·집계 | `keyword` | 특정 장르만 정확하게 필터링하거나 장르별 작품 수를 집계할 수 있다. |
| `status` | 연재중 | 정확 조건 | `keyword` | 연재중·완결 작품을 구분하여 필터링할 수 있다. |
| `start_year` | 2020 | 범위·정렬 | `integer` | 특정 연도 이후 작품을 찾거나 최신 작품순으로 정렬할 수 있다. |
| `volume_count` | 15 | 범위·정렬 | `integer` | 20권 이하처럼 권 수 조건을 적용하거나 권 수순으로 정렬할 수 있다. |
| `paper_price` | 7000 | 범위·정렬 | `integer` | 특정 가격 이하의 작품을 찾거나 가격순으로 정렬할 수 있다. |

## 4. 검색 질문과 field 연결

| 검색 질문 | 사용할 field | 확인할 역할 |
|---|---|---|
| 마법이 나오는 판타지 만화를 찾아줘. | `title`, `description`, `genre` | 전문 검색 |
| 2018년 이후 연재를 시작한 판타지 장르의 만화 중 20권 이하인 작품을 찾아줘. | `genre`, `start_year`, `volume_count` | 정확 조건·범위 |
| 장르별 만화 작품 수를 보여줘. | `genre` | 집계 |

## 5. 제외할 데이터

- 수집하거나 저장하지 않을 개인정보: 이용자 이름, 연락처, 검색 기록 등
- 제외 이유: 이 PBL은 만화 작품 자체를 검색하고 분석하는 과제이므로 이용자 개인정보가 필요하지 않다.
