# PBL 시작 카드

- 프로젝트 주제: 만화책 검색
- 사용자는 누구인가: 자신이 원하는 만화책을 찾고 싶은 사람들
- ES로 찾게 할 문서 1건은 무엇인가: 만화 작품 1개
- 사용자가 입력할 검색 질문 1: 마법이 나오는 판타지 만화를 찾아줘
- 사용자가 입력할 검색 질문 2: 2018년 이후 연재를 시작한 판타지 장릐 만화 중 20권 이하 작품.
- 사용자가 입력할 검색 질문 3: 장르별 만화 작품 수를 보여줘.
- 필터에 사용할 분류 필드 후보: 장르, 연재 상태;
- 정렬에 사용할 숫자·날짜 필드 후보: 연재 시작 연도, 권 수
- Dashboard에서 답할 질문 1: 어느 장르가 만화책 개수가 많은가?

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.
